# 个人知识库

## 概述

这是我的个人知识库，用于记录和整理学习过程中积累的知识、经验和资料。通过结构化的方式存储信息，便于后续查阅和复习。

## 内容结构

- **南京安夏/**: 包含业务平台和大模型应用管理平台相关的文档
- **浙大网新/**: 包含前置库和正式库相关的文档
- **cloud基本信息/**: 包含云服务相关的账号密码等信息
- **copilot/**: 包含Copilot相关的对话和自定义提示

## 文档格式

知识库中的文档主要以以下格式存储：
- **Markdown文件(.md)**: 用于存储结构化的文本内容
- **Word文档(.docx/.doc)**: 用于存储原始的文档资料
- **文本文件(.txt)**: 用于存储简单的文本信息

## 工具和技能

- **Doc/Docx/Txt to Markdown Converter**: 用于将Word文档和文本文件转换为Markdown格式

## 用途

- 记录学习过程中的重要知识点
- 整理工作中积累的经验和资料
- 提供便捷的信息检索和查阅方式
- 促进知识的系统化和结构化
